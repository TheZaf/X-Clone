 🚀 X (Twitter) Clone – Full Stack Social Media App

A full-stack social media web application inspired by **X (formerly Twitter)**, built with modern web technologies. This project replicates core social networking features including authentication, posting, following users, notifications, and more.
✨ Features

🔐 Authentication & Security

* User Registration & Login
* Logout functionality
* JWT-based authentication & authorization
* Secure protected routes

👤 User Profile

* View user profiles
* Edit username
* Change profile picture
* Change cover image
* Follow / Unfollow users
* Suggested users system

📝 Posts

* Create text posts
* Upload image posts
* Delete posts
* Like / Unlike posts
* Comment on posts

🔔 Notifications

* Real-time style notifications for:

  * Likes
  * Comments
  * Follows

🌍 Global State Management

* Managed using **React Query (TanStack Query)** for:

  * Efficient data fetching
  * Caching
  * Optimistic updates
  * Global server-state handling

🛠️ Tech Stack

* **Frontend:** React.js
* **State Management:** TanStack Query (React Query)
* **Backend:** Node.js + Express
* **Database:** MongoDB
* **Authentication:** JWT (JSON Web Tokens)
* **Image Uploads:** Cloud storage integration

📌 Core Functionalities Implemented

* Authentication with JWT tokens
* RESTful API architecture
* User follow/unfollow system
* Like & comment interactions
* Post creation with text & images
* Profile customization (avatar & cover)
* Suggested users algorithm
* Notification system

🎯 Project Goal

This project demonstrates the implementation of a real-world social media platform with scalable architecture, secure authentication, and modern state management practices.
